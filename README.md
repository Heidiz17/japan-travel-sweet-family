## ✨ 核心功能

* 📷 **即影即譯 (OCR)**：
  * 對準日本餐廳菜單、藥妝說明書、街頭路牌一影即譯，自動轉成地道廣東話。
* 🟢 **廣東話 ➔ 日本語**：
  * 明仔／芝女講廣東話，AI 自動翻譯並朗讀日文，方便向店員問路及落單。
* 🔴 **日本語 ➔ 廣東話**：
  * 日本人講日語，AI 即時聆聽並以廣東話朗讀出來。
* 📱 **PWA 獨立 App**：
  * 支援直接安裝到手機主螢幕，無網址列全螢幕運行，如同原生 App 般順暢。
